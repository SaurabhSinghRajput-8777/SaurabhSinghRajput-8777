<details>
<summary><b>🔷 NetSentry-DPI — Multi-threaded Deep Packet Inspection Engine</b></summary>
<br/>

A flow-aware packet inspection pipeline processing TCP/UDP/TLS traffic across concurrent Fast Path workers, using consistent hash-based routing to eliminate inter-thread lock contention.

| Aspect | Detail |
|---|---|
| **Stack** | C++17, Multi-threading, PCAP, TLS/SNI, Consistent Hashing, Lock-free Design |
| **Scale** | 4 concurrent Fast Path workers with worker-local flow tables |
| **Performance** | Zero cross-thread flow state synchronization overhead |
| **Security** | 5-tuple consistent hashing for flow affinity; TLS/SNI-aware classification |
| **Impact** | Parallel classification of HTTPS, DNS & application-layer traffic with rule-based decisions |
| **Repository** | [GitHub ↗](https://github.com/SaurabhSinghRajput-8777/NetSentry-DPI) |

Engineered for high-throughput network environments, NetSentry-DPI demonstrates systems-level command of concurrency primitives and distributed data structures — assigning flow affinity via consistent hashing to enable true lock-free parallel packet classification.

</details>
